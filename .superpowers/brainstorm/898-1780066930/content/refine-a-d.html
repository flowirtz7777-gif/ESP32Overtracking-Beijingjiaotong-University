学术刊物 × 电子墨水 — 细化方向

已选定 A（学术刊物）+ D（电子墨水），两者天然互补：期刊的严谨排版 + 纸质阅读的温润感。现在细化三个关键选择。

1. 布局结构

目前是「侧边栏参数 + 主区域图表」，整体更像控制台。改不改布局？

A

保持当前双栏布局

左侧参数面板（sticky 侧边栏）+ 右侧图表区域。只换视觉皮肤，不改结构。优点是功能不变、实现快。

B

顶部参数栏 + 全宽图表

参数折叠为顶栏（可展开），图表区域全宽排列。更像 MATLAB 文档页或论文附录的排版。参数调完就可以折叠收起，图表占满视野。

C

分区段落式（Section-based）

整页垂直滚动，每个功能块（参数/统计/轨迹/表格）是独立的 paper-like 板块。参数字段水平排布更宽。更接近学术论文单栏排版的阅读感。

2. 字体方向

中文字体影响极大。选一个你机器上有的。

A

宋体/楷体系列（中文衬线）

标题用 华文中宋/STZhongsong 或 楷体/KaiTi，正文用 Microsoft YaHei 或 PingFang。最像正式论文排版，Nature/Science 式。

B

等宽/技术体中轴

标题和数字全部 Source Han Mono / Cascadia / Consolas，字体统一但有变化。更像 MATLAB 文档、RStudio 终端的学术技术感。

C

Georgia / Times 英文 + 微软雅黑中文

英文用经典印刷衬线体（Georgia/Times），中文用雅黑。标题大号 Georgia、正文雅黑、数字和代码用 Consolas。温润的 e-ink 感。

3. 纸张底色 & 深色模式映射

电子墨水的核心是"纸感"，深色模式怎么处理？

色板预览 — 浅色(左) → 深色(右)

浅色：暖纸白

#faf7f2 底色 · #2c2416 文字 · #8b6914 强调

深色：暗牛皮纸

#26221a 底色 · #e8e0d0 文字 · #d4a834 强调

A

暖纸方向（Warm Paper）

米白暖底 + 深棕文字 + 暗金强调 + 鼠尾草绿信号色。深色模式为暗牛皮纸/咖啡底。最接近 Kindle e-ink 暖光模式，安静不刺眼。

B

冷学术方向（Cool Academic）

偏冷的象牙白底 + 深蓝灰文字 + 藏蓝/钴蓝强调。深色模式为深蓝黑底。更接近 Nature 期刊官网配色的感觉。
