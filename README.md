# 大型铰接车辆右转内轮差实时预警系统

北京交通大学2026年“挑战杯”项目。系统以车辆速度、前轮转角和铰接角为实时状态输入，通过短时耦合运动学预测构造右侧未来扫掠区，并结合雷达、视觉目标进行风险分级和报警。

## 当前阶段

- MATLAB运动学、Alpha预测方案对比、出弯状态机、TTC复盘和盲区扫描工具已经形成。
- 第一阶段位置一致性记录仍约为4至5毫米，尚未达到小于1毫米的验收门槛。
- ESP32目录仍是传感器接入骨架；预测器、风险评估、报警状态机和视觉通信尚未完成。
- OpenMV视觉融合、台架闭环和实车测试尚未进入正式验收。

PID在当前方案中只承担工况生成和对照基线角色，不是最终在线判警模型。

## 整理约定

每个工具目录至少包含入口说明和自己的输入/输出位置。历史结果不集中搬到公共目录，避免破坏实验可复现性。根目录不再放工具入口、日志、成品文档或渲染中间文件。
