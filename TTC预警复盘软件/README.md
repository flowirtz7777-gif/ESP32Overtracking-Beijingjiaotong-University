# TTC预警复盘软件

这是 `truck_slider_sim.py` 的桌面窗口版复盘工具，保留 HTML 入口。

## 启动

- 桌面窗口：双击 `启动TTC预警复盘软件.bat`
- 浏览器入口：直接打开 `index.html`

## 口径

本软件是后验 TTC 复盘工具，不是实车在线主判警程序。

- 车辆运动来自当前默认仿真或导入的完整 CSV 轨迹。
- 目标点只按中心点判定，暂不加入目标宽度。
- 目标颜色按后验 true TTC 显示，用于复盘报警提前量。
- 画面中仍显示由当前 `(v, alpha, phi)` 预测出的 `PolyW/A/I`，用于和复盘 TTC 对照。

在线主算法仍应保持：`BodyNow` 当前车身占用区兜底 + `predict_swept` 三层 poly 判定。
