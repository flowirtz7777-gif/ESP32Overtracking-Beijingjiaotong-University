# alpha 二阶外推仿真（方案 D）

α 预测改进方案之一。在方案 A（线性外推）基础上加二阶项。

## 假设

```
α(τ) = α_now + α̇·τ + ½·α̈·τ²
```

- α̇、α̈ 均由 `estimate_alpha_derivs.m` 用历史 α 序列估计，**二阶项 LPF 更强**（τ=0.35s）
- 双重限幅：|α̇| ≤ π rad/s，|α̈| ≤ 2π rad/s²，α(τ) 夹到 ±40°
- α̇=α̈=0 时退化为方案 0

## 设计意图

捕捉"方向盘正在加速回正"的二阶趋势，理论上比线性外推更贴近拐点行为。

## 局限（实测预期）

α̈ 对噪声极敏感，即便强 LPF 收益也不稳定，性价比可能低于方案 A/B。
本方案主要用于**对照说明"二阶不一定更好"**。
