# Matlab/runs/

每次执行 `run_phase1_demo` 自动生成的测试结果目录。

## 自动归档结构

每次跑会创建一个带时间戳的子目录，内含本次测试的图片与摘要文本：

```
runs/
└── 20260530_153045__pid_scenario_xxx/        # 时间戳 + CSV 文件名（去扩展名）
    ├── 01_traj_replay.png            # 图1：CSV 真值 vs MATLAB 重算 轨迹叠加
    ├── 02_state_error.png            # 图2：4 个状态分量误差时间曲线
    ├── 03_swept_polygons.png         # 图3：三层扫掠多边形 + 虚拟雷达目标 + 风险等级
    └── summary.txt                   # 测试摘要：参数 / 误差 / 是否通过门控
```

## 用途

- 算法迭代时保留历史结果，便于前后对比
- 写论文 / 申报书时直接挑选合适的图
- 调试参数敏感度（比如改了车型参数后跑同一 CSV，对比两次的图）

## Git 策略

`runs/` 整个目录已加入 `.gitignore`（图片大、变化频繁，不适合进仓库）。
若某次结果想长期保留 / 进论文，手动把那一组文件复制到 `docs/figures/` 提交。
