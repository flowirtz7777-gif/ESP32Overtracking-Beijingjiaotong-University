# alpha 方案横向对比

在**同一条 PID 工况 CSV** 下，把 5 种 alpha 预测方案放在一起跑，输出三张对比图 +
一份 `summary.txt`，用于论文 / 答辩里的"基线 vs 改进"论证。

## 被对比的 5 个方案

| 代号 | 文件夹 | α(τ) 演化假设 | 定位 |
|---|---|---|---|
| 0 | `alpha一阶保持仿真` | `α(τ)=α_now` | 基线（最小、最省，弯道收尾提前量不足） |
| A | `alpha线性外推仿真` | `α(τ)=α_now+α̇·τ` | 一阶趋势外推（α̇ 经 LPF τ=0.25s） |
| B | `alpha多假设并集仿真` | 保持 ∪ 继续打 ∪ 回正 三假设取并集 | ⭐主推，安全冗余且不过度 |
| C | `alpha扇形包络仿真` | `α(τ)∈[α₀-rate·τ, α₀+rate·τ]` 锥形包络 | 最坏情况上界（误报多，对照用） |
| D | `alpha二阶外推仿真` | `α(τ)=α₀+α̇·τ+½α̈·τ²` | 二阶外推（α̇/α̈ 经 LPF τ=0.35s） |

> 5 个方案的 `predict_swept` 签名保持一致，只在 α(τ) 假设和多边形并集逻辑上不同。
> 其余 6 个公共函数（kinematics_step / derive_points / point_in_poly /
> vehicle_params / load_pid_scenario / estimate_*）在各文件夹内是同一份。

## 运行

```matlab
cd alpha方案对比
out = compare_alpha_schemes();                                   % 默认 020804 工况
out = compare_alpha_schemes('pid_scenario_20260530_020148.csv'); % 指定其它工况
```

CSV 从基线文件夹 `alpha一阶保持仿真/scenarios/` 读取（全路径，无歧义）。

## 对比维度（三张图）

1. **`01_polyW_overlay.png`** — 同一关键帧下 5 个方案的 PolyW 轮廓叠加，
   直观看谁更大/更保守（扇形包络 C 最大、基线 0 最小）。
2. **`02_swept_area_bar.png`** — 各方案 PolyW / PolyA 的平均扫掠面积柱状图。
   面积越大 = 越保守 = 误报风险越高。
3. **`03_alarm_advance.png`** — 报警提前量：
   `lead = 物理接触时刻 − PolyA 首次预测命中时刻`，柱越高 = 越早预测到 = 越安全。
   - 物理接触时刻 = BodyNow 当前挂车矩形占用区**首次**覆盖目标（方案无关参照零点）。
   - 首次报警时刻 = 沿 ~0.15s 密集网格扫描，PolyA 首次把目标判入（**不含 BodyNow 兜底**，
     这样比较的是"预测能力"本身，而非物理到达）。

## 关键实现注意

- 用 MATLAB"**当前目录函数优先于搜索路径**"的规则：`compare_alpha_schemes` 先把
  基线文件夹 `addpath`（拿到公共函数），再 `cd` 进各方案文件夹调用其专属
  `predict_swept`，互不污染。
- 雷达目标在**世界坐标系固定**，5 个方案评估完全相同的目标，保证公平。
- 报警提前量用**密集网格**（每 ~0.15s 一次），而非 20 个稀疏关键帧——
  否则关键帧间隔(~1.4s) 远大于 PolyA 时间窗(1s≈3m)，会被物理到达时刻拉平、显示不出差异。

## 结论模板（论文可引用）

- 在平滑 PID 工况下，A/D（外推类）与基线几乎重合，因为 PID 输出 α̇ 很小；
  外推方案的价值要在**含突变/抖动的真实驾驶数据**上才体现。
- B（多假设并集）在不显著增大面积的前提下覆盖了"继续打/回正"两种司机意图，
  是面积-提前量权衡下最平衡的主模型候选。
- C（扇形包络）提供绝不漏报的理论上界，但面积过大（高速尤甚），用于证明
  "全包络太保守"，反衬 B 的合理性。
