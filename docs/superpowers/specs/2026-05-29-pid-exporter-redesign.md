## 设计哲学

### 核心审美: Nature 期刊附录风格

这个工具的本质是论文的配套仿真工具——它应该看起来像一篇 Nature/Science 期刊附录，而不是一台工业控制台。设计语言来自:

- Nature / Science 期刊的排版惯例
- MATLAB 文档页的清晰层级
- 学术论文单栏排版的克制与留白

### 三大原则

1. **数据优先，界面退后** — 图表和数据是主角，UI 框线是低调的容器
2. **纸张感，不透明感** — 浅色模式如象牙白纸张，深色模式如深夜读屏
3. **排版传达严谨** — 不同字体承担不同语义角色（参见字体层级）

### 参数区实现

取消侧边栏的 sticky 定位。参数以分类 section 水平展开:

- 车辆几何: 4 字段一行
- 仿真节拍: 4 字段一行
- 参考航向: 4 字段一行
- PID: 8 字段两行
- 物理限幅: 2 字段 + 按钮

表单 id/name 全部保留不变。

## 关键组件

### Hero 头部

- 左侧: `<img src="交大校徽.png">` + `<img src="交大校徽2.jpg">`，使用 `height: 48px; width: auto` 保持原始比例
- 右侧顶部: 主题切换（简洁文字链接或小图标，不抢眼）
- 标题: 宋体大字
- 三入口徽章: 细线框小标签，纸质感

### 主题切换

不再使用工业翘板开关。改为:

- 位置: Hero 右上角或顶栏右端
- 形式: 小号文字链接 `LIGHT ⟳ DARK`，或一个小太阳/月亮图标
- 色调: 始终低调，不抢主视觉
- 持久化: localStorage 保持不变

### 统计卡片

- 小字 label (Times New Roman, 大写, 字距拉开)
- 大号数值 (Times New Roman, 粗体)
- 底部无彩色横条（学术风格去掉此类装饰）
- 浅色: 白色卡片 + 细灰框
- 深色: 稍亮面板 + 暗边框

### 图表

Canvas 绑定逻辑完全不变。仅调整颜色方案:

- 轨迹图: 蓝色(A) / 绿色(B) / 金色(T)
- 角度图: 红色(ref) / 蓝色(theta) / 绿色(alpha) / 金色(phi)
- 网格线: 极淡灰
- 标题: "Fig. 1 — 轨迹预览" 格式

### 数据预览表

表头双行:

```
Row 1: time_s  v_input_mps  theta_ref_deg  ...  (Times New Roman, 粗体)
Row 2: 时间/秒  输入车速 m/s  参考航向 °    ...  (中文, 小号灰色)
```

表格线: Nature 三线表风格 — 顶双线 + 底双线，行间细线无竖线。

### MATLAB 代码块

- 字体: Consolas (唯一例外)
- 背景: 浅灰/深灰，无边框仅底色区分
- 标签: 右上小字 "MATLAB"
