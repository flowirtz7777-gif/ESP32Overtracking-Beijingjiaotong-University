# 人工驾驶挂车仿真软件（WASD 控制）大纲

> 状态：设计稿 v0.1　日期：2026-08-02
> 定位：人工驾驶半挂车 → 导出与 PID 工况仿真导出器**同格式**的 CSV → 喂给现有验证 / 盲区分析管线；回放并对照状态机相位。

---

## 0. 目标与定位

- 填补“只有 PID 虚拟驾驶员”的空白：提供人工驾驶数据，作为 PID 工况的对照 / 真值补充来源。
- 所有下游工具（`load_pid_scenario.m`、盲区分析软件、`truck_slider_sim.py`、正交状态机 demo）无需改动即可读取导出结果。
- 内置实时可视化（已扫掠区域 + 预测窗）+ 状态机相位日志 + 回放，形成“驾驶 → 导出 → 验证 → 复盘”闭环。

## 1. 总体架构

### 1.1 载体（建议）
- **HTML + Electron 单文件应用**，复用 `PID工况仿真导出器` 的工程模式（index.html + launch.ps1 + 启动 bat）。
- JS 运动学直接移植盲区分析软件已有的 `derivePoints / stepState / predictSwept`（同源算法，保证一致）。
- 备选：Python + pygame（手感更接近游戏），但需要重新移植/维护一套算法，不推荐优先。

### 1.2 模块划分

```
键盘事件 (W/S/A/D + 开始/结束/显示开关)
        ↓
20ms 主循环（50Hz，与 ESP32 节拍一致）
   ├─ 物理模型：油门/刹车/转向目标值按按住时长线性爬升
   ├─ 运动学积分：coupled kinematics（l_h 耦合项，phi 限幅）
   ├─ 状态机：正交路口五相判定（与 orthogonal_turn_phase 一致）
   ├─ 记录：每帧追加一行 CSV 数据
   └─ 绘制：车身/挂车 + 轨迹 + 已扫掠 + PolyW/A/I
        ↓
结束 → 导出 human_scenario_<时间戳>.csv + phase_log.csv
        ↓
Replay：回放 CSV，同步显示相位与扫掠区
```

## 2. 物理与控制模型

### 2.1 控制量定义

| 键 | 功能 | 语义 |
|---|---|---|
| W | 油门 | 按住时长 → throttle ∈ [0,1]，线性爬升 |
| S | 刹车 | 按住时长 → brake ∈ [0,1]，线性爬升，只减速不回退 |
| A | 左转 | 目标转向角按按住时长线性增大 |
| D | 右转 | 目标转向角按按住时长线性增大（负方向） |

### 2.2 油门 / 刹车（与按住时长相关，线性）

```
throttle = min(1, t_hold_W / T_ramp_w)        % T_ramp_w ≈ 1.2 s
brake    = min(1, t_hold_S / T_ramp_b)        % T_ramp_b ≈ 0.4 s
accel    = a_max * throttle - drag(v) - b_max * brake
drag(v)  = k1 * v + k2 * v^2                  % k1≈0.05, k2≈0.02（低速重卡近似）
v        = max(0, v + accel * dt)
```

- 默认参数（可界面编辑）：`a_max ≈ 0.6 m/s²`（重卡平路），`b_max ≈ 2.5 m/s²`，`v_max ≈ 10 m/s`。
- 物理依据：油门开度近似正比于牵引力 → 加速度 ≈ 开度 × 最大加速度 − 阻力 − 制动力；低速时阻力以线性 + 二次风阻近似。

### 2.3 转向（线性 + 限幅 + 速率限制）

```
target_alpha = ± min(alpha_lim, steer_rate * t_hold)     % steer_rate ≈ 25°/s
alpha        = clamp(alpha, ±alpha_lim)                  % alpha_lim = 30°
phi          = clamp(phi, ±phi_max)                      % phi_max = 15°（随参数面板）
```

- 松开 A/D 后 alpha 按同样速率限制回正到 0。
- **符号约定**：正 alpha = 左转（逆时针），负 alpha = 右转，与 `omega1 = v*sin(alpha)/l` 一致；A 键 → alpha>0。

### 2.4 运动学

- 严格复用 coupled kinematics：`omega2 = (vB*sin(phi) + l_h*omega1*cos(phi)) / L`（**l_h 耦合项不可省略**）。
- 每帧输出与 PID 导出器一致的 A/B/H/T 坐标。

## 3. 实时信息与可视化

- 顶部 HUD：时间、v、a、alpha、phi、theta、轨迹长度、当前状态机相位。
- 轨迹线：B 点历史路径。
- **已扫掠区域**：历史车身矩形（A/B/H/T 四点矩形）隔帧采样并集 / 描边。
- **预测窗**：当前帧 `(v, alpha, phi)` → PolyW（2s）/ PolyA（1s）/ PolyI（0.3s），`dt_pred=0.02`。
- **显示/隐藏按钮**：一键切换“已扫掠 + 预测窗”图层（默认显示）。

## 4. CSV 导出（格式兼容）

### 4.1 列定义

- 与 PID 工况仿真导出器**完全一致**的列（`load_pid_scenario` 的 required_cols）：
  `time_s, dt_s, v_input_mps, l_m, l_h_m, L_m, width_m, phi_max_rad, theta_ref_rad, theta_ref_deg, theta_rad, theta_deg, theta_t_rad, theta_t_deg, alpha_rad, alpha_deg, phi_rad, phi_deg, e_theta_rad, e_phi_rad, xA_m, yA_m, xB_m, yB_m, xH_m, yH_m, xT_m, yT_m`
- **末尾新增一列**：`accel_mps2`（实际纵向加速度）。
- 已核实三个消费端均容忍额外列：
  - `load_pid_scenario.m`：readtable + 只校验必需列；
  - 盲区分析软件 `parseCSV`：按表头泛化读取；
  - `truck_slider_sim.py`：DictReader 按名取值。

### 4.2 人工驾驶无参考航向的处理

- `theta_ref_rad/deg`：填 `theta`（误差恒为 0），保持列存在且物理自洽；
- `e_theta_rad / e_phi_rad`：填 0（这两个列不在 required_cols 中，但保留以保持同格式）；
- `dt_s`：恒定 0.02；`phi_max_rad` 必填（老工具缺列时回退 45°，显式写更稳）。

## 5. 状态机阶段日志

- 复用正交路口五相判据（IDLE/ENTRY/MID/EXIT/DONE），JS 移植自 `orthogonal_turn_phase.m`，默认阈值：alpha_start=2°，enter_hold=2 帧，mid=25°，exit=75°，done=88°，各保持帧数 2/2/10。
- 侧车文件 `phase_log.csv`（不污染主 CSV）：
  `time_s, phase, event, alpha_deg, phi_deg, heading_delta_deg`
  - event：`FIRST_ENTRY / ENTER_MID / ENTER_EXIT / ENTER_DONE` 等相位切换事件。
- 实时 HUD 显示当前相位，人工驾驶时可直接对照。

## 6. 回放 Replay

- 加载刚导出的 CSV（或任意 PID 格式 CSV）。
- 渲染与实时驾驶一致：车身/挂车、轨迹、已扫掠、PolyW/A/I、当前相位。
- 播放控制：播放 / 暂停 / 拖动进度条 / 倍速。
- （可选）导入目标点 CSV，叠加显示在线判警结果，与盲区分析软件对照。

## 7. 与现有工具链的衔接（验收路径）

1. 导出 CSV → `load_pid_scenario` 成功读取（新增列被忽略），`run_phase1_demo` 重算误差 < 1mm 门控；
2. 同一 CSV → 盲区分析软件导入 → 得到盲区日志；
3. `phase_log.csv` 与 MATLAB `orthogonal_turn_phase` 输出逐帧对比一致；
4. 同一 CSV → **TTC 预警复盘软件**导入（`parseCSV` 泛化读取、不检查必需列）→ 用 `验收目标集` 的目标 CSV 看真值 TTC 与固定窗口 Poly 的对照；
5. Replay 画面与 `truck_slider_sim.py` 对照。

> 分工说明：**TTC 预警复盘软件**提供后验真值 TTC（“现实中还有多久撞上”），其 PolyW/A/I 是固定窗口参考，**不读 CFG 策略**；人工驾驶下的**策略表现**（预测窗、盲区点、相位切换）以**盲区分析软件** + MATLAB `validate/scan` 为准。
