# 工作复盘

每次发 release 后由 AI 助手生成一份复盘文档存放在此目录。

## 命名约定

```
v<版本号>_<简短主题>.md
```

例：
- `v1.0.0_项目立项.md`
- `v1.0.1_Phase1算法收敛.md`

## 内容模板

每份复盘至少包含以下章节：

1. **时间线总览** — 这一版做了什么，按时间顺序
2. **当前状态矩阵** — ✅已完成 / 🟡部分完成 / 🔴待办
3. **关键技术成就** — 论文/答辩可用的亮点
4. **风险与注意点** — 已识别但未解决的问题
5. **git/版本现状** — 当前 tag、分支、远端状态
6. **下一步建议** — 优先级排序

## 触发条件

- 每打一个 `vX.Y.Z` tag 后，写一份对应的 `vX.Y.Z_*.md`
- 即使是补丁版本 (v1.0.1, v1.0.2 ...) 也要写
- 写完一并 commit + push，作为该 release 的"工程档案"

## 关系

- `预测模型与对照模型构建思路.md` — 顶层论证（不变）
- `CLAUDE.md` / `AGENTS.md` — 工程执行手册（持续更新）
- `docs/预测与判警算法说明.md` — 当前算法实现说明（持续更新）
- `TODO.md` — 待办登记
- **`工作复盘/v*.md`** — 每个版本的快照式复盘（每发版加一份，不修改旧的）
