# alpha 多假设并集仿真（方案 B · 保守并集对照）

α 预测的保守并集对照方案。不赌单一未来，而是覆盖所有合理意图。

> 定位说明：本方案曾被标为"主推"，后因实测 PolyW 平均面积明显增大
> （6.88m² vs 基线 4.56m²）而 canonical R3 提前量无实质改善，重新定位为
> **保守并集对照**。主线已转向"出弯相位识别 + 受限回正预测 + TTC 复盘验收"。

## 假设

同时演化三种 α(τ)，取扫掠区**并集**：

```
假设1 (保持):     α(τ) = α_now
假设2 (继续打):   α(τ) = α_now + α̇·τ            （沿当前趋势，α̇ 经 LPF）
假设3 (开始回正): α(τ) = α_now - sign(α_now)·25°/s·τ
最终危险区 = Poly(假设1) ∪ Poly(假设2) ∪ Poly(假设3)
```

## 设计理念（论文核心卖点）

**不预测司机意图，而是覆盖所有合理意图** → 符合安全系统第一原则：宁可多覆盖不漏报。
只要有一个假设抓到目标就报警，从而解决 R3 类"恒定假设漏报"问题。

## 局限

危险区偏大 → 误报率上升，需要报警状态机滞回（N_up=2 / N_down=10）缓解。
