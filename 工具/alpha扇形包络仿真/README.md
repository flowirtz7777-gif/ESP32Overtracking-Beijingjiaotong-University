# alpha 扇形包络仿真（方案 C）

α 预测的**理论上界**模型，用作对照。

## 假设

方向盘在物理转向速率上限 rate (=25°/s) 内可朝任意方向变化：

```
α(τ) ∈ [α_now - rate·τ,  α_now + rate·τ]   （随 τ 张开的锥形）
扫掠区 = 该区间扫出的所有车身位置包络
```

实现：在锥形内取 7 条分支 α 轨迹（含上/下界 + 中线），收集右外缘点 → polyshape union。

## 定位

- 数学上是"未来 T_h 秒物理可达的所有危险区"，**绝不漏报**
- 但区间越往后张得越大 → 高速时危险区可能大到不实用，误报极多
- **作对照**：证明"全包络太保守，方案 B 更平衡"
