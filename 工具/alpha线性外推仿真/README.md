# alpha 线性外推仿真（方案 A）

α 预测改进方案之一。与基线 `工具/alpha一阶保持仿真/` 的唯一区别在 α(τ) 演化方式。

## 假设

```
α(τ) = α_now + α̇_filtered · τ
```

- α̇ 由 `estimate_alpha_dot.m` 用历史 α 序列的**因果一阶低通**估计（LPF τ=0.25s）
- 双重限幅：|α̇| ≤ π rad/s，α(τ) 夹到 ±40°
- α̇=0 时退化为方案 0（恒定保持）

## 解决的问题

基线"α 恒定保持"在弯道收尾、方向盘正在回正阶段偏保守 → R3 类目标报警偏晚。
线性外推能抓住"正在打 / 正在回"的一阶趋势，提前量更足。

## 局限

转弯**拐点**处线性外推会过冲（不知道方向盘要回头）。
