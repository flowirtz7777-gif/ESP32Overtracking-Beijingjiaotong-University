# 预测算法与驾驶因素实验总计划

版本：2026-10-14-v1。状态：当前v3已完成S0/S1/S2，S3完成43/624项后触发目录预算保护并保存断点，当前没有实验进程运行。实际参数与运行约束补充见[夜间首批执行协议](执行协议_夜间首批.md)，最新进度见[续跑阶段记录](reports/续跑实验进度与阶段结论.md)，夜间阶段记录另行保留。

## 1. 研究目标和结论边界

主目标：在明确的车型、低速右转范围、统一真值和误报约束下，选出漏报/迟报较少、计算开销可接受的完整预警方案。

副目标：解释牵引车车速、前轮转角变化率、入弯/回正动作如何影响各预测方法，以及这些因素是否改变算法排名。

最终分别报告两个结论：相同后处理下的核心预测方法表现；各方法经过相同预算调参后的完整系统表现。允许报告多种权衡方案或所有方案均不满足条件，不强行指定唯一赢家。

研究先限定为低速、无轮胎侧滑的耦合运动学和静态空间目标。载荷、附着、轮胎动态、目标运动及实车测量另作扩展；没有被模型表达的因素不参与本阶段的有效性声明。有限仿真零漏报不等于实车安全保证。

## 2. 旧实验封存和新的起点

封存范围：`../自动化批量实验/`内全部旧计划、脚本、输入、结果、日志、源码快照，包括早期窗口比较、第1至6轮及中断的第8轮诊断。

旧目录原地冻结为只读，另生成完整ZIP与逐文件SHA-256。保留原路径，是因为既有脚本/结果有绝对路径和相对依赖。旧`active_experiment_plan.json`保持原内容作为历史材料，不再代表当前活动计划；当前计划为本目录`plan.json`。完整快照恢复可复核历史，但旧运行器恢复执行须另建可写副本并明确解封。

新实验不继承旧候选排名、滤波最优值、目标坐标、轨迹或评分结果。新生成规则、公式实现、评价器和参数候选都单独编号和冻结。现有耦合运动学公式可作为基线；新代码通过独立校验后才能使用。

现有工具的两个限制必须在S0解决：旧默认轨迹为PID生成且车速恒定，不能直接拿控制器增益当作驾驶员转向速度；默认铰接角被夹到15度，不能通过这种夹断得到新真值。旧名为制动的轨迹没有真实变速，不能作为制动实验。

## 3. 变量分层与处理顺序

| 层次 | 本阶段控制/改变的内容 | 管理规则 |
| --- | --- | --- |
| 车辆固定参数 | 轴距、牵引销偏置、挂车等效长度、宽度、初始姿态 | 基础27条轨迹全部固定；尺寸扩展单列 |
| 驾驶动作 | 车速曲线、前轮转角曲线、入弯/回正速率、转角峰值 | 由离线轨迹生成器显式指定，不通过调整PID间接实现 |
| 观测条件 | 噪声、偏置、尖峰、延迟、时间戳误差、丢帧 | 同一真值上生成不同观测；算法间共用扰动 realization 和种子 |
| 核心预测 | 保持、线性、衰减线性、受限二阶 | 基础比较共用预处理、窗口、几何和报警条件 |
| 二级处理 | 扩窗、膨胀、确认/撤销、阶段切换 | 先统一，再联合比较；不逐项拼接所谓最优值 |

顺序：测量及时间戳 -> 因果状态估计 -> 当前阶段判定 -> 选预测形式与窗口 -> 耦合推演 -> 逐段扫掠 -> 空间膨胀 -> 目标命中 -> 确认/撤销 -> 报警。

扩窗改变推演时间；膨胀改变空间边界；确认改变命中序列的输出时间。它们有交互：窗口乘上趋势强度；膨胀可能延长连续命中；扩窗和膨胀可能重复覆盖同一目标。不得把联合收益解释成单项效果相加。

## 4. 车辆与驾驶动作的可控定义

第一阶段沿用一组公开标注为仿真示例的几何参数：牵引车轴距4.0m、牵引销前向偏置1.8m、牵引销至挂车后轴13.5m、等效宽度2.0m；初始车身对齐、铰接角0、从直行进入90度右转。这不是实车标定。

车速统一定义为牵引车后轴中心的纵向速度`v_B`，候选为2、3、4m/s，即7.2、10.8、14.4km/h。现有公式的`v_input`沿前轮滚动方向，二者关系`v_B=v_input*cos(alpha)`；新生成器必须显式换算，记录两个字段，避免转角改变时实际车速也被隐式改变。

“方向盘速度”本阶段用前轮转角速率`dalpha/dt`表达，基础候选为2、4、8度/s；方向盘到前轮的映射待实际车辆标定后换算。固定峰值前轮转角绝对值10度，采用三个动作模板：

| 动作模板 | 入弯速率 | 回正速率 |
| --- | ---: | ---: |
| 对称动作 | r | r |
| 较快入弯 | 2r | r |
| 较快回正 | r | 2r |

三个车速乘三个r乘三个动作模板，共27个设计组合。10度转角和速率档位是第一批仿真设计值，S0必须检查其实际达到的值与可行性，不解释为真实车辆操作范围。

转角曲线为直行、入弯、保持、回正、直行；连续变化，速率切换采用固定0.2s平滑过渡。保持段时长离线求解，使总航向变化为90度；它是由控制因素决定的从属量，必须输出，不能说所有组合拥有相同路径或转弯时长。前后直行记录各至少6s和8s。

参考真值不夹断铰接角。先以45度作为本批仿真研究范围的候选限制，超出则标记不可行并报告，不强行截到限制值。若某组合无法满足转角、速率、总转角或研究范围，S0修订整个设计版本后重建；不静默替换或删除不利组合。

两类速度问题分别研究：

- 控制输入实验：使用上述车速×转向速率设计，路径可以随输入变化，研究可控驾驶因素及交互。
- 同路径重放：将3条已通过验收的代表路径按2、3、4m/s重放，共9个设计组合；目标坐标完全共用，接触时刻随速度重算。转向速率会随时间重标定改变，因此其结论是相同路线提速的综合影响，不能声称保持转向速度不变的纯速度效应。

## 5. 真值、目标集和公平比较

真值采用独立的高精度参考积分实现，与在线预测器分离；保留`l_h*omega1`耦合项。使用更小参考步长检查收敛，并验证直行、恒定转角的牵引车轨迹和铰接连续性。目标首次接触必须基于与评分一致的连续/逐段扫掠，不允许只在稀疏快照上判定而把中间接触漏掉。

同一轨迹所有算法、窗口、膨胀、确认方案共用同一目标坐标、真值标签、观测文件和评分时段。不同输入产生不同路径时，统一空间采样规则和分层权重；不能为凑同一坐标而丢失某路径的真实危险区域。

目标分三层：右侧边界邻域、扫掠内部、距真值扫掠外侧0.5m内的近场非接触点。边界带候选宽0.20m。各层报告实际数量和各自指标；主要汇总采用预先固定层权重，而不是受各层点数比例影响的合并百分比。不复制点，不用远处空地补负样本。

FRONT首次进入点按用户要求忽略，单列数量；内部点保留。RIGHT为主要接触评价对象；角点归类、LEFT和REAR必须固定定义并另表，不把小区域按面积删除。

先用嵌套网格0.10、0.05、0.025m做密度检查，分别检查绝对指标和算法配对差异。点数由有效区域容量决定，预计约2万至3.5万点仅作计算预算参考。正式阶段每条轨迹冻结一套经过验收的目标集；若需更密复验，所有对照使用共同新版本，旧密度结果不直接与新密度百分比相减。

几何容差基准0.05m，与算法膨胀距离分别记录。容差在整个主实验中固定；0.025/0.10m只用于敏感性附表，不能用改真值容差提高排名。

主反应时间阈值1s。所有组合采用相同可评分时段：启动前2s不评分，记录末端共同截去3s，满足最大正式窗口3s。未来扩大窗口时须创建新共同评分版本并全部对照重算。真值未来仅在离线评分使用，在线算法无权读未来转角、接触时刻和真值阶段。

扩窗会改变“未来W秒内会接触”的逐帧真值范围，因此同时输出各自W口径和共同2s参考口径，不能只因3s把原先过早命中划为真阳性就声称精度提高。逐点记录首次原始命中、首次确认、各自窗口内有效命中、接触前提前量；过早报警与从不接触点误报分别计数。

## 6. 分阶段实验与转段条件

| 阶段 | 内容与控制 | 输出 | 转段条件 |
| --- | --- | --- | --- |
| S0 基础验收 | 新轨迹生成、独立真值、几何与接触、目标密度、时间戳与因果性、实际计算预算 | 验收记录、27条轨迹可行性表、冻结版本 | 所有基础问题解决；不通过则修基础 |
| S1 核心方法与驾驶因素 | 27条轨迹上4方法；无噪声/延迟；W=2s、膨胀0、确认0、速度保持；统一历史估计器 | 基础108个方法×轨迹作业；速度/转向速率/动作交互表 | 核心误差和失效工况可解释；相同预算细化后保留两种方法及保持基线 |
| S2 观测与状态估计 | 相同真值上施加扰动；分别检查因果滤波与时间戳补偿，不同时改报警规则 | 干扰敏感性、估计滞后、可复现失败样例 | 至少3种子；明确收益和回归；冻结共同输入处理候选 |
| S3 二级处理联合实验 | 两种方法×EXIT W 2/3s×膨胀0/0.02/0.05m×确认0/0.1s | 24个基础配置、配对交互表与权衡曲线 | 相同误报预算下选候选；无可行方案则报告不可行 |
| S4 完整方案与适用范围 | 对前两名小范围联合细化；同路径速度重放；必要时单独检验阶段切换 | 稳定参数区间、阶段消融、9个同路径重放工况 | 新选择轨迹复核；排名对密度/步长/容差小变化稳定 |
| S5 冻结最终验证 | 固定算法、参数、评价器后生成至少18条未看过的轨迹；加入约定扰动 | 最终总表、失败边界、计算开销 | 不重调最终测试；失败转回新研究版本，不改称通过 |

S1方法定义：

- 保持：未来前轮转角保持当前值。
- 线性：利用仅过去数据估计的转角变化率外推，名义倍率g=1。
- 衰减线性：趋势随未来时间衰减，例如`alpha(u)=alpha0+g*alpha_dot0*tau_d*(1-exp(-u/tau_d))`。
- 受限二阶：历史数据估计转角加速度，限定幅值和生效时长，之后接连续的线性延伸；防止二阶项长期增长。

共用转角/速率物理限值与历史输入定义；具体限值必须在S0冻结。S1先比较名义实现，再对各方法进行最多16个有效配置的相同预算搜索，轨迹分组交叉检查。保持方法没有对应参数时不复制重复作业；线性与二阶不得使用未来导数作输入。每个作业可共享0.3/1/2s预测前缀，三个窗口的评分数不是三个独立驾驶试验。

S2先使用6条预先按速度/速率/动作分层选出的代表轨迹，覆盖低、中、高动作强度。观测条件包括clean、白噪声0.5/1/2倍参考量级、纯50/100/200ms延迟，以及100ms延迟叠加1倍噪声。随机条件用3个冻结种子，噪声参考量级须新登记，不继承旧候选最优结果。固定偏置、相关噪声、尖峰、丢帧属于单列压力集，不把所有因素一次铺满笛卡尔积。数据年龄来自显式测量时间戳；仿真生成元数据不作为未来状态输入。

S3包含每种方法不扩窗/不膨胀/无确认的基线，即使该方法在S1没进前两名，保持基线仍以独立回归行保留。确认与撤销规则必须完整记录，不能把降低报警频率称作预测误差减少。必要时加入趋势倍率0.75/1/1.25，基础24配置扩至最多72个有效配置；不适用参数不做重复笛卡尔积。

S4阶段自适应仅在数据支持时添加：对比固定策略与仅改变一个阶段参数的策略，在线阶段从观测推断，真值阶段仅用于离线分层。若共同误报预算无可行解，优先查可复现失败机制，再决定是否扩大候选家族/改确认规则，不能自动把更大膨胀设为赢家。

## 7. 开发、选择与最终测试

27条基础轨迹为开发与驾驶因素研究集。另建12条选择轨迹：同一车辆、在规定范围内改变中间档速度/转向速率及曲线形状，检查候选稳定性。该选择集允许参与系统选择，因此与开发集一起视作调参数据，不称最终独立测试。

最终至少18条轨迹的生成规则和随机种子在打开最终分数前冻结；候选确定后才运行。包含新的曲线形状、规定范围内的中间/边界档位，以及独立压力工况。车辆尺寸扩展和真实变速按不同范围单列表；若首版模型未实现，不填已完成。最终数据仍为同类运动学仿真，不能代替实车泛化证据。

同一轨迹的不同噪声种子、密集目标和连续帧不是独立车辆试验。按轨迹及动作家族汇总配对差异，报告范围和失败数量；样本不足时不声称统计显著。重复运行完全相同输入只用于复现/计时。

## 8. 指标、预算和选择原则

核心指标：0.3/1/2s未来右边界误差、扫掠漏覆盖与多覆盖面积、RIGHT目标窗口漏报率、迟报率、接触前完全无报警、有效提前量分位数。

系统指标：近场非接触点误报率、逐帧误报率、每分钟错误报警持续时间、报警闪烁/撤销次数；同时保留原始分子分母和各层权重。面积指标必须基于所有逐段区域的完整并集，不以大外轮廓替代，也不按面积删分支。

主图为漏报/迟报与误报负担的权衡曲线；在共同误报预算下比较各方法。首版探索预算沿用近场点误报5%、逐帧误报0.5%，重新冻结分层采样后才使用；它们是研究约束，不是安全认证标准。零RIGHT窗口漏报和零接触前完全无报警是有限最终集的研究目标；达标后再比较迟报、误报和耗时。无方案同时达标时报告无可行解。

不能只用一个加权分数选算法，不把误报大幅上升的零漏报方案直接叫最佳。同时展示平均、最差工况和每个失败场景；不同最坏指标可能来自不同轨迹。

计算开销记录纯预测/几何/判定时间及P50/P95/max，排除浏览器渲染和CSV写出。50Hz回放下20ms是桌面实验设计周期，不声称桌面达标即ESP32达标；固件移植后需实机复核。

密度与数值稳定性候选门：目标加密后关键配对差异变化不超过0.20个百分点、提前量分位数变化不超过0.05s；真值加密后的边界差不超过0.005m。绝对率与配对差异分开验收。若排名或零漏报结论对边界步长敏感，暂不冻结算法，继续修正数值基础。

## 9. 结果保存和执行边界

新数据、代码、日志、结果只写入本目录后续新增的`src/`或版本化`src_v*/`、`datasets/`、`runs/`、`reports/`。场景、目标、观测与生效算法配置均带ID、版本和SHA-256；每个作业留逐点压缩结果、逐帧记录、摘要及源码快照。源文件变化时新建版本，不混入已有断点。

计划制定时仅做计划和封存；随后用户已授权执行。实施从S0开始，先做9条代表组合预检，基础门通过后才进行批量搜索。空间不足时保存断点，不删除封存历史；先测每作业耗时、内存、磁盘，再定并发。运行状态以当前检查点和阶段记录为准。

第一批交付应为：新输入生成器、独立参考真值、目标与标签校验、冻结的27条轨迹设计和有效性表、S0验收报告。只有通过后才开始108项核心比较。
