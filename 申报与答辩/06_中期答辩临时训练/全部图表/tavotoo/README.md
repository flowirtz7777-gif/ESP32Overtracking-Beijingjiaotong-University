# 中期答辩图表：Tavotto 编辑包

工具正式名称是 **Tavotto**；本目录按你的命名保留为 `tavotoo`。本包收录当前“全部图表”中的 **60 张图**，每张均配有独立 Python 入口、同名 PDF 和 PNG 预览。输入表、绘图依赖和原程序参考副本均在本目录内。

本包只读取已经生成的结果表或现有 SVG，供调整字体、配色、图例和版式使用。不会重新训练、重新运行车辆仿真或修改科研标签。图中保留中期临时结果的原有说明。

## 最快用法

1. 打开已经安装的 Tavotto 桌面应用。
2. 将整个 `tavotoo` 文件夹设为图库即可查看全部 60 张图，也可以按下表分别打开分类子文件夹。模型图现已添加 `M1__`、`M2a__`、`M2b__`、`M3__`、`M4__` 前缀，整个图库内的输出名唯一。每个分类也保留自己的 `tavotto_registry.json`。
3. 从素材库把所需 **PDF** 拖到画布上，双击进入图内编辑；若提示连接源程序，选择旁边的同名 `.py`，入口为 `__main__`，再进行试运行/连接。
4. 从元素树或画布选中文字、图例、曲线等，调整字号、颜色、位置和线型。修改由 Tavotto 单独保存。保留项目文档，导出 PDF 用于排版，导出 PNG 用于 PPT。
5. 导出到图库的 `tavottofile/export`，或自己选择新的输出文件名，方便保留初始版本。

打开子图库时，父目录的 `_data` 和 `site-packages` 仍需保留，**移动或备份请复制整个 `tavotoo` 文件夹**。不需要打开或执行 `_source_reference` 里的参考程序。公共绘图模块现已放入 `site-packages`，该依赖目录不会被 Tavotto 扫描成独立图。

界面中的“脚本尚未运行”表示尚未完成 Tavotto 当前会话的首次连接，可以点右侧三角按钮；“已取消”表示上次试运行被取消。它们本身不表示图的数据或程序出错。

## 两张案例图的编辑边界

58 张图由现有结果表和原绘图逻辑重新构造 Matplotlib Figure；汇总图使用已保存的分档表重绘。**没有再次拟合模型或选择参数。**

`fig13_案例_预测区叠加` 与 `fig14_案例_报警接触时间轴` 的原程序会调用仿真和报警重放。本包改为读取它们已经生成的 SVG，将文字、路径和形状重建为 Matplotlib 对象。这两张图可做呈现层编辑，但有以下区别：

- 子图坐标轴在本包里是页面坐标下的矢量对象，不具备原始科学坐标轴的完整联动行为；不要通过修改页面坐标轴的数值来调整物理范围。
- 原 SVG 中的稠密点云位图层仍是位图，不能逐点编辑；没有把整张 PNG 当成可编辑矢量图。
- 修改模型参数、案例选择、数据或统计数值仍须回到原程序及相应受控流程。这里保留原 PDF/PNG，便于对照。

## 文件和验证

- 每个分类：同名 `.py`、`.pdf`、`.png`，以及分类注册表。
- `_data`：本地输入表、已保存的模型预测/指标、ROC/PR 原图曲线数组及两张案例的 SVG。
- `site-packages`：`_support.py`、`_plot_*.py`、`_svg_replay.py` 公共绘图模块；与 pip 安装无关，不要单独作为图来运行。
- `_source_reference`：原绘图程序的文本副本，仅供核对；其中可能包含原来的训练/仿真调用，不作为 Tavotto 入口。
- `figure_manifest.json`：全部 60 张图、来源和复制文件的 SHA-256。
- `validation_report.json`：Matplotlib 重建与 PDF 输出检查。
- `tavotto_engine_validation.json`：改名前的首轮单图渲染检查记录；它未检查整库 stem 唯一性，不能作为整库接入通过的依据。
- `latest_package_validation_v2.json`：更名后的整库唯一性、真实安装版 Tavotto CLI 对全部 60 张图的脚本/PDF 关联检查，以及 32 个更名入口的渲染检查。以此记录核对当前版本。CLI 自检不打开新的窗口，不等于逐张 GUI 拖拽验收。
- `bundled_runtime_validation_v3.json`：当前 v3 的验证记录，直接使用与正在运行的 Tavotto 桌面应用相同的自带 Python、safe worker、图库根目录与沙盒机制逐张捕获 Figure 和编辑元素。**当前版本以此记录为准**，而非仅用项目 Python 完成的早期检查。
- `bundled_dependency_fix_v3.json`：取消 `sklearn` 绘图依赖、原曲线数值逐点一致性及公共模块移动记录。
- `registry_name_fix_20261023.json`：本次问题原因和 32 张模型图的新旧名称映射。
- `package_check.json`：文件完整性、注册表和来源哈希复核。

**避免直接重跑上级 `汇总/collect_figures.py`：原脚本会递归删除“全部图表”下的 PNG，也会影响本包中的 PNG 预览。** 若日后重新收集全部图，请先备份这个编辑包及 Tavotto 修改记录。

本次改图包不改变原图、原程序、原实验结果或训练的认证状态；它只是中期展示结果的编辑入口。
