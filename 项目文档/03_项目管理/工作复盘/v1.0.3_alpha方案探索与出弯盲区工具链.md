### 关键认知演化（按发生顺序）

1. **先做加法**：建了 alpha A/B/C/D 四个外推方案，一度把多假设并集（B）当"主推"。
2. **用户纠偏（方法论）**：
   - 评估口径错误——对比脚本各方案各自现造目标点，导致 summary 里 R3 接触时刻
     (17.92s) 与复盘文档固化 R3 (16.24–18.12s) 对不上，结论不可横比。
   - 机理判断——R3 不是"alpha 外推阶数不够"，是"出弯阶段识别 + 阶段化预测"问题。
     出弯阶段危险由 **φ 滞后**主导，不由 alpha 主导；外推 alpha 是在调错变量。
3. **做减法 + 归因**：固定 canonical R3，hold 基线三路对比诊断。
4. **证伪自己的猜测**：原怀疑"polyshape 取最大连通区域误删内切窄条"——诊断显示
   PolyA 层 R3 落入被丢弃区域的帧数 = 0，**该猜测被证伪**。
5. **定位真因**：连真值扫掠 swept_truth 自身也要到 15.80s 才纳入 R3，瓶颈在
   **horizon 内的 φ 姿态演化**，不在多边形后处理。
6. **用户定调**：alpha 一阶保持即可，**仅在 EXIT 出弯阶段扩窗**（由状态机门控），
   不全局扩窗、不改 alpha。R3 只作方向指引，不再死磕单点指标。

## 三、关键技术成就（论文/答辩可用）

1. **alpha 假设的系统性扫描**：5 个方案（hold/linear/union/fan/quad）量化对比，
   实测扇形包络面积 39m²（基线 4.56m² 的 8.5 倍）→ 用数据证明"全包络过保守"，
   反衬阶段化策略的合理性。这是一组现成的"基线 vs 改进"对比图。

2. **盲区的时间安全再定义**：`lead_W = 真实接触 − 首次报警 < 反应阈值` →
   把"盲区"从静态视觉遮挡升级为时间安全概念，沿整条右沿铺 2000 点全图扫描，
   产出"反应阈值 vs 盲区点数量"曲线。对论文很有说服力。

3. **归因方法论的自我证伪**：诊断脚本设计成能否定作者自己的假设（三路对比 +
   被丢帧计数），干净排除了"取最大块误删"猜测，把矛头精准指向 horizon 内 φ 演化。

4. **阶段化预测雏形**：出弯相位识别（航向累计 + α·α̇<0 + φ 滞后）+ 仅 EXIT 扩窗，
   一次只动一个变量（时间窗），安全膨胀接口预留但禁用——工程克制的范例。

## 四、风险与注意点

### 风险 1：仅 EXIT 扩窗可能对 R3 实际无效（最高优先）

R3 物理接触 16.30s、PolyA 首次报警 15.80s。若 EXIT 相位首次触发晚于 15.80s，
则 R3 报警时系统仍在 MID 相位用 1.0s 窗，扩窗未生效。**上线前必须先跑 demo 看
EXIT 首次触发时刻**，否则是"看着合理、对 R3 无效"的改动。

### 风险 2：盲区扫描器尚不能论证本方案

扫描器写死 `T_h_W=2.0`，未接相位门控。要量化"仅 EXIT 扩窗"的净收益，必须先把
扩窗逻辑接进扫描器，跑"固定窗 vs 仅EXIT扩窗"全图对比。

### 风险 3：90° 正交假设

`exit_heading_th=75°` 是十字路口右转假设。020804 是合成 PID 工况恰好转够 90°；
真车若只转 70–80°，EXIT 永不触发。需在 CLAUDE.md 标明边界。

### 风险 4（沿用）

HTML 轴距硬修正的 ~4mm 残差；实车 α/φ 标定占位；硬件团队进度滞后。

## 七、本版核心教训

1. **先想清楚再做加法**：一上来建了 4 个 alpha 外推方案，结果机理判断错了——
   出弯危险由 φ 主导而非 α，4 个方案大多是在调错变量。**应先做单点归因，
   再决定要不要批量铺方案。**

2. **评估口径必须冻结**：各方案各造目标点直接让结论失去可比性。固定目标集
   （`验收目标集/`）是这次补上的方法论补丁。

3. **诊断要能证伪自己**：对"取最大块误删"的猜测，做了能否定它的三路对比实验，
   避免了"我以为对了"的自我循环——这正是 v1.0.1 复盘里写下的教训的兑现。

4. **工程克制**：最终方案（一阶保持 + 仅 EXIT 扩窗）一次只动时间窗一个变量，
   安全膨胀接口预留但禁用。比"改 α 阶数""全局扩窗""扇形全包络"都更可辩护。
