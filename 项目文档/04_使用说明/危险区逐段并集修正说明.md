# 危险区逐段并集修正说明

修正日期：2026-10-13。项目目录：`E:\大创内轮差项目`。

## 修改目的

取消“对自交大多边形简化后仅保留面积最大区域”的规则。区域小不代表没有碰撞风险；同时，大多边形的偶奇填充也不等于时间扫掠并集。

## 当前几何定义

1. 按各方案原有转向假设递推车辆状态。
2. 每两个相邻预测时刻取挂车H-T右侧边缘的四个端点。
3. 对这四个端点构造局部凸包；共线时保留极端线段，重合时保留点。
4. 将所有局部片按OR解释，构成时间并集；多假设及扇形方案还对所有分支取并集。
5. 目标判定、图形显示和面积统计使用同一组片。面积是几何并集面积，不是各片面积之和。

这个局部凸包是线性端点插值的保守覆盖，不是整个预测窗口的全局凸包，也不是连续真实车辆运动的无漏报证明。连续转动和数值积分仍需步长收敛、独立轨迹验证。

## 修改范围与接口

- 五个alpha预测分支及正交出弯状态机：统一更新predict_swept、point_in_poly及绘图调用。
- 每个上述MATLAB工具新增一致的swept_step_hull、swept_segments、swept_polyshape、plot_swept_region辅助函数；文件哈希已核对一致。
- alpha方案对比：面积改用并集面积，图形改用完整并集，新增几何口径说明。
- 全过程盲区网页：逐段判内和逐段显示同步采用局部凸包。
- MATLAB目标核验、阈值扫描及正交状态机统计：逐段判定同步更新。
- 新日志口径为`segment_convex_union`。历史runs、日志和冻结目标集未覆盖。
- R3诊断仍保留旧最大区域规则用于历史归因；已修改注释，明确不是当前预测器。
- 六个demo把过长标题拆行，并将“关键帧未命中”等同于“车不会扫到”的旧描述改为非逐帧结论。

MATLAB预测输出仍为N×2矩阵，但NaN分隔的是待取并集的各扫掠片，并非普通多边形的连续边界。不要删除NaN、直接拼接所有顶点、直接套鞋带公式或以偶奇规则解释所有片。

```matlab
hit = point_in_poly(x, y, poly);       % 所有片按OR命中，包含边界
shape = swept_polyshape(poly);        % 合并填充片，保留区域与孔洞
coverage_area = area(shape);          % 重叠不重复计数
plot_swept_region(poly, [0.2 0.6 0.5]);
```

point_in_poly默认1e-9米只是数值边界容差，不是安全膨胀；第四参数可指定距离容差。退化线段/点参与判定，但面积为零。BodyNow当前车身兜底继续独立保留。

网页“Poly大多边形参考”模式仍为旧可视化参考，不参与新版统计；该参考模式下点着色也不应用于新版几何验收。默认逐段模式显示参与新版判定的局部片。
