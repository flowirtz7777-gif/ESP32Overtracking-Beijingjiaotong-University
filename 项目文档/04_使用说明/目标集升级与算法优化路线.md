## 三、必须分清评价范围

当前内部生成范围是整个等效H-T挂车矩形，不包含牵引车、真实车尾后悬及目标自身尺寸。当前主预测器主要预测挂车右侧边缘。

nearest_contact_edge表示离首次采样接触位置最近的矩形边缘：

- RIGHT / LEFT：右侧 / 左侧。
- FRONT / REAR：H端 / T端。
- CORNER：距离并列的角部。
- INITIAL_OVERLAP：记录起始即处于占用区或判内容差内。
- NONE：整段记录没有采样接触。

它是诊断辅助描述，不是严格的碰撞进入方向证明。不能仅凭这个字段自动认定所有角部属于右侧；应结合轨迹复盘和任务范围。

如果研究目标是右侧内轮差危险，应主要报告右侧目标，并单独审查角部与核心R3反例。若目标扩展到全部车身碰撞，则需要补齐未来车身占用区/端部覆盖，不能只靠扩大右侧边缘区域。

每个候选方案还应单独跑`验收目标集/出弯测试.csv`，尤其R3。新采样集不能代替固定反例验收，也不能只挑新点集里表现好的结果。

## 四、指标与观察期

- 有效危险目标：记录中确认接触，且没有被前沿忽略或起始截断排除。
- 漏报：有效危险目标没有PolyW预测命中。
- 晚报：接触时间减首次PolyW命中时间小于固定反应阈值。
- 预警不足率：(漏报+晚报) / 有效危险目标数。
- 负样本误报率：FALSE_POSITIVE / (FALSE_POSITIVE+CORRECT_REJECTION)。
- FRONT_CONTACT_IGNORED、STARTUP_TRUNCATED和END_TRUNCATED单列，不混入相应分母。
- 分别报告RIGHT、FRONT等分组，不能把全挂车结果冒充右侧结果。

这些是静止点、当前模拟工况下的目标级指标，不是实车事故概率，也不是逐帧误报率。某个最终会接触的目标是否曾被过早、错误地预测到，仍需要后续逐帧“实际接触是否落在对应预测窗口内”的评价。NO_CONTACT_IN_RECORD只保证当前离散记录内未接触，不代表记录之外永远安全。

判内容差默认5厘米是评价设置，不是已经实现的安全膨胀。算法比较时固定接触判据、反应阈值、目标坐标和观察期；不能通过调松这些设置使盲点数字变小。

## 七、算法优化方向

| 候选 | 作用 | 建议 |
|---|---|---|
| 转角保持 | 简单稳定的基线 | 保留，不直接撤掉 |
| 受限线性趋势 | 用当前转角变化率预测继续转向/回正 | 优先比较，导数须只用历史数据、滤波并限幅 |
| 二阶外推 | 加入转角变化率的变化 | 留作对照，不因阶数高就认定更准 |
| 受限多假设 | 保持、受限趋势、回正三种可能性 | 优先候选；回正到零停止，反打应独立定义 |
| 分阶段窗口 | 在风险较难预测的阶段调整视野 | 与“全程大窗口”做消融，证明分阶段独立收益 |
| 有限安全膨胀 | 覆盖状态、目标和几何误差 | 与数值容差分开，先固定小范围搜索，再考虑不确定性传播 |

“微分”是估计转角变化率的步骤，不是独立的预警算法。一阶保持在本项目中指转角不变；线性外推才使用一阶导数。二阶微分会更敏感于噪声；铰接角仍应由耦合运动学递推，不独立随意外推。

滤波应使用因果历史窗口。默认对称Savitzky-Golay平滑会使用窗口两侧数据，不能直接作为无延迟在线输入。原始说明：[MathWorks sgolayfilt](https://www.mathworks.com/help/signal/ref/sgolayfilt.html)。

安全膨胀可先在MATLAB用圆角几何buffer建立对照，实时端再采用等价的距离判定并验证。MathWorks的[polybuffer](https://www.mathworks.com/help/matlab/ref/polyshape.polybuffer.html)支持按距离扩展区域，但它不能替代误差标定。本次没有启用CFG中的安全膨胀字段。

建议路线：校核物理定义与时间对齐 -> 明确右侧/整车评价范围 -> 固定目标及阈值 -> 保持/线性/二阶/受限多假设统一裁判 -> 分阶段窗口消融 -> 有限膨胀权衡 -> 未参与调参的工况与噪声/延迟验证。

最值得优先试验的是“保持基线 + 受限趋势/回正多假设 + 分阶段窗口 + 有上限的误差膨胀”，但尚未证明它最优。正式优化前，车速定义与铰接角硬限幅仍需校核；当前CFG裁判链仍只执行hold，候选算法还需要接入统一评价入口。
